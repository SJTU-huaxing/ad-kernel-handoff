# 第 348 步故障与数值修复

第一版正式 AD 训练在第 348 步检测到非有限梯度，出错步骤未执行 AdamW 更新，队列自动停止。softmax 当时已完成 1,600 步、104,857,600 tokens，验证 PPL 为 57.8074；这些初版轨迹已保存在 `work/pretraining/archive/protocol_v1_global_scaling/`，不混入修复版对比。

从第 256 步保存状态重放，在相同步数再次触发矩阵乘法反向异常。长重放的浮点轨迹与原运行存在微小差异，因此这里称故障重现，不声称恢复后的全部参数逐位一致。提取出的独立回归输入是第 8 层、batch index 4、head index 6，包含 1,024 个位置的 log-Q、log-K、V 和真实上游梯度。

根因是整个序列共用每个 feature 的最大 K 对数作为计算缩放。该样本的 K 对数范围约为 −81.2 至 32.7；未来的大 K 把早期因果分母缩小到约 `1.48e-44`。数学上分子和分母应同时约消，但 FP32 的极小非正规数与反向中间量无法可靠表示。

| 执行方式 | 输出最大绝对误差（对 CPU FP64） | Q/K 梯度有限 |
|---|---:|---|
| 原 CPU FP32 | 0.393 | 否 |
| 原 NPU FP32 | 1.125 | 否 |
| NPU 强制保持原数据类型 | 1.125 | 否 |
| 修复后 NPU FP32 | 约 1.6e-6 | 是 |

CPU 也发生同类错误，且 NPU 精度选项未消除错误。证据见 `work/reproduction/training_failure_step348/isolated_regression.json`。

修复先计算缩放后的实际因果分母。如果其中最小值小于当前浮点类型 `sqrt(finfo.tiny)`，就把执行区间分成两段。第一段输出完整 S、z 和数值缩放，第二段继续使用这些状态；两段之间的状态梯度完整保留。必要时继续细分，直到该表示具有足够的指数范围。阈值仅选择等价计算路径，不加到分母，也不替换或截断分母；模型的 K 幅度、feature 函数和全历史因果上下文保持原定义。

这增加了数据相关的执行开销。正常范围使用原来的批量 GEMM 分块路径；极端输入的递归重试最坏可增加 `O(T log T)` 的 feature 扫描，不能把所有输入下的执行成本都描述为严格线性。正式结果必须报告实测吞吐、状态成本和数值分段次数。

另外，全 padding 区间返回的空状态现在携带 `-inf` 数值缩放，防止它在续接时压低幅度很小的第一个有效 K。状态仍为零，未引入额外记忆。

验证包括实际故障 head、实际全尺寸模型 batch、未来 K 幅度相差 100/200/1000 的输入、初末状态梯度、padding、因果性及续接。集成修复在实际故障 head 上的 Q/K/V 梯度相对 RMS 误差约为 `2.6e-6 / 4.4e-7 / 3.1e-7`；测试证据分别保存在 `stable_integrated.json`、`full_model_integrated.json` 和 `work/logs/test-stable-v2-cpu.log`。完整训练能否长期稳定仍需由后续实际运行确认。
